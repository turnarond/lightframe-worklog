# CI 自动化门禁

- 日期：2026-11-21
- 工作流：`.github/workflows/ci.yml`
- 运行环境：GitHub Actions `windows-latest`，Node 24

## 触发

- push 到 `main`
- push `v*` tag
- Pull Request
- 手动 `workflow_dispatch`

## 门禁步骤

| 步骤 | 判据 |
|---|---|
| `npm ci` | 干净安装；Electron 45 由 postinstall 下载 |
| Electron 包/二进制一致 | `node_modules/electron/package.json` 版本 == `dist/version` |
| `npm test` | 151/151 |
| 逐文件 `node --check` | 每个文件退出码 0 |
| `npm audit --audit-level=high` | 无 high/critical；6 项 dev-only moderate 不阻断 |
| `npm run smoke:boot` | 无 `[boot] 启动失败`，页面 ready |
| `verify-lan --self-host` | 9 项 PASS |
| `npm run pack:dir` | 生成 `dist/win-unpacked` |
| 产物 Electron 串 | `光影工作志.exe` 含 `Electron/<安装版本>` |
| `npm run smoke` | 打包版 UI 烟测全 PASS |

## 本地复跑

```bash
npm ci
npm test
for f in main.js preload.js src/*.js tools/*.js server-lite/*.js; do node --check "$f" || exit 1; done
npm audit --audit-level=high
npm run smoke:boot
node tools/verify-lan.js --self-host
npm run pack:dir
npm run smoke
```

## 边界

- CI 不构建 NSIS、不发布 Release、不签名；发版仍走干净 worktree + `release_gate.py` + 人工授权。
- Windows runner 的 GUI 会话若影响 Electron 烟测，需单独调整；首次推送后观察 Actions。
- 工作流存在不等于分支保护；建议在 GitHub 设置 `Windows gates` 为 required status check。
- 审计阈值只拦截 high/critical；构建链 moderate 作为已知风险保留。
- 首次运行需下载 Electron 45 与依赖，约 5–10 分钟；后续可加 Electron 缓存。
