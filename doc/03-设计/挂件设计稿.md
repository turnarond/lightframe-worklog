# 桌面挂件（#1）前端设计稿

> 状态：**设计冻结待确认**（工程治理 Step 0 已对齐「整窗变半透明挂件」方向，本稿为外观/内容/交互设计，需用户签字后转入 TDD 实现）。
> 改动级别：Major（触及 `SPEC §1` 产品定位），版本建议 **v2.0.0**（实现时同步修订 SPEC/白皮书边界条款）。

## 1. 目标与定位
把应用从「窄条常驻小工具」变为**贴在桌面上的半透明日历挂件**，像 Desktop Calendar 那样与桌面融为一体：
- 置顶、可拖拽、半透明（可调）、圆角无边框、玻璃拟态
- 以**月历为主**，当日任务清单为辅
- 闲置时几乎「消失」成桌面的一部分；鼠标移入才显出控件

## 2. 形态与窗口
- 无原生标题栏，`BrowserWindow` 设 `transparent:true` + `frame:false` + `alwaysOnTop:true` + 自定义拖拽区
- 默认尺寸约 **320×360**（紧凑）；允许用户拖到桌面任意位置，位置记忆到 `settings`
- 提供「鼠标穿透」开关：开启后整窗 `pointer-events:none`，仅顶部手柄可交互（便于真正当成桌面背景的一部分）

## 3. 布局（自上而下）
1. **手柄条**（高 22px，仅它始终可交互）：应用名 + 拖拽 grip；穿透模式下是唯一抓手
2. **头部**：`M月D日 周X` · 实时 `HH:MM` 时钟 · `＋` 新建 · `⚙` 设置
3. **月历**：`‹ 年月 ›` 导航 + 星期行 + 6×7 日期网格
   - 今日：实心 accent 圆角高亮
   - 有任务的日子：底部小圆点
   - 非本月：淡化
4. **今日任务**：标题 + 优先级色点（高红/中橙/低绿）+ 截止日；可滚动，最多显示若干条

## 4. 视觉（玻璃拟态 token）
- 背景：`rgba(247,240,228,0.55)` + `backdrop-filter: blur(14px) saturate(1.15)`
- 边框：`rgba(125,46,46,0.18)`；圆角 16px；柔影 `0 10px 34px rgba(40,25,10,.22)`
- 默认透明度 **0.9**（v2.8.1 订正：代码实际一直为 0.9；本设计稿曾计划 0.55），设置可调 0.2–1.0（设置→外观滑块）；模糊 0–24px 可调
- 复用现有暖纸色板（`--paper/--accent/--ink…`），保持与现有三 Tab 一致的质感

## 5. 交互
- 拖拽手柄移动；位置/透明度/模糊落盘到 `settings`
- **双击某天** → 以该天为截止日新建任务（复用 v1.1.0 速记/详情逻辑）
- **单击某天** → 底部任务列表切换到该天
- **双击任务** → 打开 v1.1.0 已交付的详情编辑弹窗
- 悬浮显控件，移出渐隐为纯玻璃

## 6. 内容/数据规则
- 月历数据来自现有 `taskModel`（按 `dueDate` 聚合），不新增存储
- 今日任务沿用现有排序与优先级着色
- 详情编辑、日报/周报仍保留（可作为挂件内可展开面板或独立窗口，待确认）

- 不引入联网、不接大模型（#3 另行排期）
- 不改动任务数据模型与存储格式（仅消费现有字段）
- 大模型的「智能日报」(#3) 与本月历视觉(#1) 解耦，分别交付
