## 问题与影响

- v2.8.1 安装包 82.7 MB，其中 41 MB 是 55 个 Electron 语言包；应用自身 `app.asar` 仅 6.6 MB。
- 用户对安装包体积有疑问；需要在不影响功能的前提下降低分发体积。
- 试验构建证明：仅保留 `zh-CN` / `zh-TW` / `en-US` 后，安装包 82.7→75.5 MB，解包 275→236 MB。

## 设计决策

- `build.electronLanguages` 设为 `["zh-CN","zh-TW","en-US"]`，删除其余 52 个 `.pak`。
- `build.files` 增加 `!src/**/*.test.js`，不把测试文件打进应用。
- 不做 `compression: maximum`（electron-builder 文档称收益不明显）；不删 Chromium 许可证文件（合规风险）；不引入 Tauri 重写。
- 不修改任何运行时代码或数据格式。

## 验收判据

- NSIS 安装包体积 ≤ 76 MB（实测 75,437,057 字节 / 71.9 MiB）。
- `dist/win-unpacked/locales` 仅 3 个文件；`app.asar` 不含 `*.test.js`。
- 打包版 UI 烟测连续 3 次 PASS；`npm test` 151/151；启动烟测 PASS；语法与局域网自测通过。
- Release 资产名称/哈希与 `latest.yml` 一致，发布后匿名 latest 与资产可访问。
