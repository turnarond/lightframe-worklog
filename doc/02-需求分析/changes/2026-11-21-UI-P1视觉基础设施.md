## 问题与影响

- 可读性：`--ink-faint` 在纸底对比度仅 1.92:1，却用于空态、保存提示、分组计数与删除按钮；
  `--accent` 小字仅 3.52:1，白字按钮 3.98:1，均低于 WCAG AA。
- 控件一致性：手柄 5 个按钮使用 `▣ — ✕ ☁ ⚙` 五种字形，视觉重量与语义不一致。
- 文案：设置页「关闭窗口时收到托盘」为错别字。
- 空态：仅有斜体灰字，缺少下一步引导；同步状态只有纯文本，没有状态色。

## 设计决策

- 新增 `--accent-ink: #a34a2f`：纸底 5.0:1、白字 ≥5.65:1（纯白 5.87），用于小号强调文字与按钮底色；
  `--accent` 保留给装饰/大面积填充。
- `--ink-faint` 只做装饰；必要元信息改用 `--ink-soft`（4.82:1），最小字号提升到 11px。
- 手柄按钮改为统一 16px 线性 SVG，保留原有 ID、aria-label 与点击区。
- 空态文案改为「没有数据 + 下一步动作」；同步状态增加状态色圆点。
- 不改信息架构（展开态重复列表、快捷日期统一留到下一刀）。

## 验收判据

- 关键文字对比度：必要元信息使用 `--ink-soft` 或更深；小号强调文字使用 `--accent-ink`。
- 手柄 5 个按钮均为 SVG，ID/aria 不变；无横向溢出。
- 设置文案为「收至托盘」。
- 空态有具体引导；同步状态有圆点与颜色。
- `npm test` 151/151；`smoke:boot` PASS；打包版 `npm run smoke` PASS；截图复核无布局破坏。

## 风险

- 强调色加深后整体观感会略偏沉稳；需要截图确认仍保留暖纸气质。
- SVG 图标为手写路径，已用打包版烟测验证 24px 点击区、无横向溢出与拖拽占比。
- 对比度调整只覆盖当前选择器；后续新增文本需沿用 token 约束。
- 字号存在 v2.6 缩放块（文件末尾）覆盖前文声明的机制；本卡已同步该块，后续改字号必须两处同时检查。
- 非中英系统下 Electron 内置 UI 回退英文（与语言包裁剪一致），应用界面仍为中文。
