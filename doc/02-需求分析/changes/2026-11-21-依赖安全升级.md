- `electron-updater` 保持 6.8.11（已是最新；随 builder-util-runtime 升级验证）。
- 不改应用源码、数据格式、同步协议；如升级暴露 Electron API 问题，单独修复并记录。

## 风险

- Electron 33→45 跨 12 个大版本，可能移除/改变主进程 API、CSS 或默认安全策略；打包版烟测是硬门禁。
- electron-builder 26 可能改变 NSIS 产物命名/配置 schema；需重新核对 latest.yml 与资产名。
- **体积回退**：干净构建安装包 113,861,261 字节，比 v2.9.0 的 75,437,486 字节增加约 38.4 MB（+51%）；安全修复与体积不可兼得，需用户决定是否接受。
- 自动更新链路（electron-updater 6.8.11 + Electron 45 + builder 26）未做端到端升级演练；发版前建议补一次。
- Chromium 156 对 Windows 10 早期版本的最低要求需真机确认。
- 残留 6 项 moderate 位于构建链（minimatch 等），不进入用户运行时；修复需破坏性 override，未采用。
- 主仓本地 `node_modules` 仍是「包 45 / 二进制 33」的混合态（WorkBuddy 锁）：任何直接 `npm run dist` 都会产出
  Electron 33 安装包，且既有门禁会通过。发布构建必须从干净 worktree `npm ci` 完成；用户侧 `npm ci` 会按 lock 安装 45。
- 未签名状态不变，SmartScreen 行为不变。
- 若升级导致无法在合理时间内修复的回归，回退到 v2.9.0 依赖并登记未决风险。
