## 问题与影响

- v2.10.1 安装包 113,943,750 B；解包 331.8 MB，其中 Electron 运行时占绝大多数。
- 实测可裁剪且本应用不使用的文件：
  - `dxcompiler.dll` 24.6 MB（DirectX Shader Compiler / WebGPU，本应用为 2D UI）
  - `ffmpeg.dll` 3.0 MB（音视频解码，本应用无媒体功能）
  - `resources/default_app.asar` 0.1 MB（未使用）
- 保留：`vk_swiftshader` / `vulkan-1` / `d3dcompiler_47`（GPU/RDP 回退）、`icudtl.dat`、
  `resources.pak`、许可证与三语言包。

## 设计决策

- 新增 `scripts/after-pack-slim.js` 作为 electron-builder `afterPack` 钩子，在打包后、NSIS 前删除上述文件。
- 删除失败即构建失败，避免“以为裁了、其实没裁”。
- 不做激进裁剪（不删 Vulkan/SwiftShader/d3dcompiler/许可证），避免 RDP/VM 渲染与合规风险。
- 不改业务代码、数据格式与同步协议。
