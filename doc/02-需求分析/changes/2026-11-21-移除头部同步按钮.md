# Change Card: 2026-11-21-移除头部同步按钮

- 日期: 2026-11-21
- 负责人: 闫朝东（AI 代理执行）
- TDD 深度: tdd:浅（理由：UI 入口收敛，无数据/同步协议变化；以启动烟测、打包版烟测与测试回归为证据）
- 基线冻结: 不适用：不编辑数据层与同步逻辑

## 问题与影响

- 手柄倒数第二个按钮（循环箭头）与最后一个按钮（滑杆）在行为上都打开设置弹窗；
  前者只是额外聚焦「服务器地址」，视觉上两个都像设置，容易误解。
- 头部 5 个按钮在 420px 宽度下偏拥挤；同步是可选的低频配置。
- 不处理的后果：用户持续把同步入口当第二个设置，且头部空间被低频入口占用。

## 设计决策

- 移除 `#w-sync` 头部按钮；同步配置与状态全部保留在设置页 `#sync-block`。
- 删除 `updateSyncIndicator()`、`w-sync` 事件绑定与 D 映射，以及 `#w-sync.is-on` 样式。
- 头部由 5 个按钮变为 4 个：展开 / 隐藏 / 退出 / 设置。
- 不改同步协议、数据结构、设置页同步控件与状态点。

## 验收判据

- DOM 中不存在 `#w-sync`；头部无横向溢出。
- 设置页同步区（服务器地址、同步码、启用/生成/复制/立即同步）与状态点仍可用。
- `npm test` 151/151；`smoke:boot` PASS；打包版 UI 烟测 PASS。
- 无 console.error、无未捕获异常。
