# 光影工作志 · Lightframe Worklog

[![CI](https://github.com/turnarond/lightframe-worklog/actions/workflows/ci.yml/badge.svg)](https://github.com/turnarond/lightframe-worklog/actions/workflows/ci.yml)

常驻 Windows 桌面的半透明工作挂件。核心链路：

> 随手记任务 → 按项目分类 → 完成 → 每天汇总日报 → 每周汇总周报 → 一键复制发出

- **形态**：Electron 桌面挂件（`v2.0.0` 起整窗半透明、置顶、可拖拽，像桌面日历贴在屏幕上）；开机自启；关窗最小化到系统托盘常驻
- **全局唤起**：`Ctrl+Shift+Space` 随时弹出速记小窗
- **视觉**：暖纸手账（浅色纸质纹理 + 火漆红强调色）+ 玻璃拟态

设计依据见 [`doc/01-蓝图/产品规格-光影工作志.md`](./doc/01-蓝图/产品规格-光影工作志.md)，实施计划见 [`doc/03-设计/实施计划与迭代记录.md`](./doc/03-设计/实施计划与迭代记录.md)，桌面挂件设计稿见 [`doc/03-设计/挂件设计稿.md`](./doc/03-设计/挂件设计稿.md)。

> 当前版本：**v2.11.0**（2026-11-21，数据安全闭环）。

## 一、快速开始

```bash
npm ci           # 首次需联网下载 Electron 运行时（约 180 MB）
npm start        # 启动应用
```

其他命令：

| 命令 | 说明 |
|---|---|
| `npm test` | 跑单元/集成测试（161 项，不依赖 Electron）：`node --test src/*.test.js server-lite/*.test.js` |
| `npm run icon` | 重新生成 `assets/icon.png` |
| `npm run dist` | 打包 Windows 便携版 `exe`（输出在 `dist/`） |

> 首次 `npm ci` 若因网络中断导致 Electron 二进制缺失（`node_modules/electron/dist/electron.exe` 不存在），补跑一次 `node node_modules/electron/install.js` 即可。

## 安装（Windows）与未签名提示

从 [GitHub Releases](https://github.com/turnarond/lightframe-worklog/releases) 下载 `lightframe-worklog-setup-X.Y.Z.exe`，不要从第三方站点获取。

> **当前安装包未做代码签名**，Windows SmartScreen 可能显示「未知发布者 / Unknown app」。点「更多信息」→「仍要运行」即可；这是未签名程序的系统提示，不代表安装包损坏。

下载后建议校验 SHA-256（v2.11.0，安装包约 101.1 MiB）：

```powershell
Get-FileHash .\lightframe-worklog-setup-2.11.0.exe -Algorithm SHA256
# 期望：4350DA3C714BDF1072A0E98B02D9975AFAFC96B7F6CC1B636CEF0C58ED96CE0A
```

哈希不匹配时不要运行。代码签名方案见 `doc/05-运维/2026-11-21-SignPath代码签名接入.md`（当前暂缓）。

## 二、怎么用

### 1. 记任务
- 主界面任务 Tab 顶部速记条：**标题 + 分类（默认沿用上次）+ 优先级 + 截止日**，回车即存
- 任意时刻按 **`Ctrl+Shift+Space`** 弹出速记小窗：`Enter` 保存并关闭，`Esc` 取消
- 列表按 **逾期 → 今天 → 即将 → 未安排 → 已完成** 五组归类；组内按优先级 → 截止日 → 创建时间排序
- 行内可直接改截止日与优先级；点左侧圆点勾选完成
- 下方迷你月历：每天显示未完成任务圆点，点某天即筛选当天到期任务

### 2. 写日报
- 日报 Tab 自动汇总当天**已完成**（按 `completedOn` 统计）的任务，按项目分组
- 手写三栏：**今日进展 / 问题与风险 / 明日计划**，输入即自动保存
- 可翻到前后任意一天补写；底部 **一键复制日报** 直接进剪贴板

### 3. 出周报
- 周报 Tab 默认本周（周一为起始，ISO 周编号），可前后翻周
- **本周完成**按项目分组；**本周进展 / 问题与风险**自动聚合该周 7 天对应栏
- **下周计划**预填本周最后一天写的「明日计划」，可改后自动按周保存
- 底部 **一键复制周报**

### 4. 提醒（系统通知）
> 2.5.1 起合并为单条「每日待办」提醒，不再区分日报 / 到期两套。

| 提醒 | 触发 | 内容 | 跳过条件 |
|---|---|---|---|
| 每日待办 | 每天 17:00–21:59 每小时一次（22:00 后停） | 今日到期 / 逾期任务 + 日报是否未写 | 当天日报已写且无限期 / 逾期任务时不弹；按「日期 + 小时」去重 |

前提：开机自启 + 关窗收托盘（不退出）。

### 5. 设置（标题栏齿轮）
- **分类管理**：项目/模块单级枚举，可增删（至少保留一个）
- **提醒**：两类提醒的时间与开关
- **常驻**：开机自启、关闭窗口时收托盘
- **速记快捷键**：默认 `Ctrl+Shift+Space`，改完回车生效；组合键无效或被系统占用时自动退回默认键并提示
- **数据与备份**：自动备份开关、恢复点列表、立即备份、导入/导出、打开备份目录

## 三、数据存在哪

四个 JSON 文件，位于 Electron `userData` 目录：

```
C:\Users\<用户名>\AppData\Roaming\lightframe-worklog\
├── tasks.json       任务列表
├── dailyLogs.json   每日三栏日志（以日期 YYYY-MM-DD 为键）
├── settings.json    分类枚举、自启/置顶/收托盘、快捷键、周计划、同步码
├── syncmeta.json    同步游标与最近同步时间（未启用同步时不存在）
└── backups/         自动恢复点（最近 10 份 + 每日 7 份）
```

备份或迁移，直接拷这四个文件即可（未启用同步时没有 `syncmeta.json`）。

### 自动备份与恢复

- 每次写盘前自动生成一组一致的恢复点，保留最近 10 份 + 最近 7 天每天 1 份。
- 设置 → 数据与备份：立即备份、整份恢复、导入/导出、打开备份目录。
- 恢复会整份覆盖任务/日报/设置，并**暂停同步**；确认后可在同一区块恢复同步。
- 自动备份包含同步码；手动导出默认脱敏，勾选后才包含。
- JSON 损坏时应用不会静默清空，会提示从备份恢复或导出原文件。

## 五、关键设计约束（改代码前请先读）

1. **`completedOn` 与 `dueDate` 必须分离**。日报/周报按实际完成日期 `completedOn` 统计，逾期判定按 `dueDate`。若复用 `dueDate` 做完成统计，「上周到期、本周才完成」的任务会算进错误的周报。
2. **17:00–21:59 每小时合并提醒一次「每日待办」**（到期 / 逾期任务 + 是否写日报），22:00 后停。
3. **`lastReminded.todoHour` 按「日期 + 小时」去重**，防同一小时重复弹。
4. **关窗不退出**：`before-quit` 置 `isQuitting`，`close` 时改为 `hide`；只有托盘右键「退出」才真正结束进程。
5. **全局快捷键注册失败不得崩溃**：主进程 try/catch + 返回值判断，失败回退默认键。
6. **渲染层所有 IPC 调用包 try/catch**，失败弹提示条而非白屏。

## 七、残留问题（按严重度）

| 级别 | 问题 | 说明 / 规避 |
|---|---|---|
| P2 | 提醒依赖应用在运行 | 开机自启 + 托盘常驻已覆盖日常场景；整天未启动则当天提醒不再补发 |
| P3 | 无数据导出与备份 | 手动拷贝四个 JSON；单个文件损坏时读取层降级为空（等于丢弃该文件） |
| P3 | 便携版多开会有并发写覆盖 | 最后写入者生效，同一份数据请勿同时运行多个副本 |
| P2 | 安装包未签名 | SmartScreen 显示「未知发布者 / Unknown app」；按本文安装说明校验 SHA-256 后运行；SignPath 申请暂缓 |
| P3 | 通知受系统通知中心控制 | 开启「专注助手/勿扰」时可能被静默 |

按 SPEC 明确不做的：默认不联网（可选「同步码多设备同步」，需用户显式配置）、无工时统计 / 计时器、无报告模板自定义、无文件导出、无移动端。

> **当前（v2.11.0）**：已提供**可选的同步码多设备同步**——极简服务端在 `server-lite/`，默认仍是纯本地单机，不配置同步码就不会联网。设计见 [`doc/03-设计/设计稿/2026-11-06-同步码多设备同步-设计.md`](./doc/03-设计/设计稿/2026-11-06-同步码多设备同步-设计.md)，部署见 `server-lite/README.md`。

## 八、风险与注意

- Electron 首次安装需联网下载约 180 MB 运行时。
- Windows 通知需 `app.setAppUserModelId` 已设置（已实现）。
- 打包便携版依赖 electron-builder 下载 Windows 工具链，离线环境会失败。
- 提醒定时器为 60 秒轮询 + 「到点后补发一次」策略，跨睡眠唤醒后仍会补提醒。
